# spec：策略越复杂，表现就越好吗？——检查交易规则负担

> 在当前项目中执行命令，使用本 spec 指定的环境。遵守 TRAE 当前的权限设置；需要额外权限时，先说明原因和访问范围，取得用户确认后再继续，不要求关闭沙箱或启用“完全访问”。

## 上下文

在 `q6-avoid-overfitting.ipynb` 中已有：
- 参数优化结果及其样本内简化夏普与样本外简化夏普的比较
- 滚动式前推验证与锚定式前推验证
- 5 折时间序列交叉验证

现有实验主要检验参数选择。本实验进一步检查逐步增加交易规则、扩大调参范围时的过拟合风险。

## 任务目标

通过 2 个堆叠实验，检查增加交易规则和可调参数是否加重过拟合风险。

4A 固定动量窗口和波动率窗口，先优化再平衡间隔，再逐步增加交易规则并优化相关阈值；4B 从优化动量窗口开始，逐步把更多参数纳入优化，后期也增加交易规则。2 个子实验都会增加可调参数，但扩展路径不同，不把它们作为分别只增加交易规则或可调参数的 2 组对照实验。

## 执行要求

沿用 spec 01 的分段独立回测设置：各段从初始资金开始，指标只使用本段数据计算，包含段首等待指标形成的过程，不承接前一段的持仓。

1. 阅读下列 open-xquant 源码，了解所列交易规则类及其参数：
   - `oxq.rules.RebalanceFrequencyRule` – 再平衡间隔规则，`interval_days` 表示再平衡间隔
   - `oxq.rules.StopLossRule` – 止损交易规则（`threshold`）
   - `oxq.rules.TakeProfitRule` – 止盈交易规则（`threshold`）
   - `oxq.rules.TrailingStopRule` – 移动止损交易规则（`trail_pct`）
   - `oxq.rules.MaxDrawdownRisk` – 最大回撤风控规则（`max_drawdown`）
   - `oxq.core.Engine.run(..., rules=[...])`
   - `ParameterSet.add_constraint()` 的约束表达式格式

2. 继续使用第 1 个实验中为兼容当前 open-xquant 接口编写的辅助函数：
   - `BookCompatibleSimBroker`
   - `split_strategy_rule_params()`
   - `apply_params_to_strategy_and_rules()`
   - `run_with_params()`
   - `grid_search_with_rules()`
   - 运行输出中不得出现无效参数警告

3. 编写 `run_layer(layer_name, rules, paramset, description)`：
   - 复用第 1 个实验中样本内数据与样本外数据的切分
   - 如果 `paramset` 为空，直接跑固定参数基础策略
   - 如果 `paramset` 非空，只使用样本内数据运行 `grid_search_with_rules(...)`
   - 取样本内最优参数后，只用该最优参数跑一次样本外验证
   - 打印每层组合数、样本内简化夏普、样本外简化夏普、累计收益率和简化夏普差

4. **4A（交易规则堆叠）**：
   - 在首次使用前定义 3 组阈值候选值：止盈阈值 `TP_THRESHOLDS = [0.05, 0.10, 0.15, 0.20, 0.30]`，移动止损阈值 `TRAIL_PCTS = [0.03, 0.05, 0.07, 0.10, 0.15]`，最大回撤风控阈值 `MAX_DD_VALS = [0.05, 0.08, 0.10, 0.15, 0.20]`
   - 基础策略：使用 `TopNRankingOptimizer`，固定参数 `mom.period=20`、`vol.period=20`、`interval_days=10`，单位均为交易日
   - 规则传入 `Engine().run(..., rules=[...])`
   - 第 0 层：基础策略（固定再平衡间隔，不优化其他交易规则）
   - 第 1 层：优化再平衡间隔（`interval_days = FREQS`，约束 `interval_days <= mom.period`）
   - 第 2 层：增加止损交易规则并优化止损阈值（`sl = SL_THRESHOLDS`）
   - 第 3 层：增加止盈交易规则并优化止盈阈值（`tp = TP_THRESHOLDS`，约束 `sl < tp`）
   - 第 4 层：增加移动止损交易规则并优化移动止损阈值（`trail = TRAIL_PCTS`，约束 `trail >= sl`）
   - 第 5 层：增加最大回撤风控规则并优化最大回撤风控阈值（`max_dd = MAX_DD_VALS`，约束 `max_dd >= sl`）
   - 每层使用样本内数据选出最优参数，再使用样本外数据验证
   - 按本实验设定的约束筛选组合：固定止损阈值<止盈阈值、移动止损阈值⩾固定止损阈值、最大回撤风控阈值⩾固定止损阈值

5. **4B（可调参数递增）**：
   - A：只优化动量窗口（1 个可调参数，`PERIODS`）
   - B：增加波动率窗口（2 个可调参数）
   - C：增加再平衡间隔（3 个可调参数，约束 `interval_days <= mom.period`、`interval_days <= vol.period`）
   - D：增加止损阈值（4 个可调参数，约束同 C）
   - E：增加止盈阈值和移动止损阈值（6 个可调参数），同时缩小部分参数的候选取值范围，以控制组合数。具体候选值如下：
     - 动量窗口和波动率窗口均为 `[10, 20, 30]`，单位为交易日
     - 再平衡间隔为 `[5, 10, 21]`，单位为交易日
     - 止损阈值为 `[0.03, 0.07, 0.15]`
     - 止盈阈值为 `[0.10, 0.20, 0.30]`
     - 移动止损阈值为 `[0.05, 0.10, 0.15]`
     - 应用约束 `interval_days <= mom.period`、`interval_days <= vol.period`、`sl < tp`、`trail >= sl`
   - 每层使用样本内数据优化所有参数，再使用样本外数据验证
   - 按各配置列明的约束筛选组合；止损阈值、止盈阈值和移动止损阈值的大小关系与 4A 一致
   - 可调参数数量与有效组合数分开统计。候选值和约束条件也会影响组合数，因此可调参数增多时，组合数不一定随之增加

6. 打印 2 个汇总表：
   - 4A：层名、描述、组合数、样本内简化夏普、样本外简化夏普、简化夏普差、样本内累计收益率和样本外累计收益率
   - 4B：配置名、可调参数数量、组合数、描述、样本内简化夏普、样本外简化夏普和简化夏普差

7. 画图并保存：
   - 在一张大小为 16 英寸×8 英寸的画布中并排绘制 2 个折线图。
   - 左图展示 4A 各层的样本内简化夏普与样本外简化夏普，标题为“4A（交易规则堆叠）”。
   - 左图横轴名称为“实验层级”，刻度依次为“第 0 层”“第 1 层”“第 2 层”“第 3 层”“第 4 层”“第 5 层”。各层的具体调整见 4A 汇总表，不在图中重复列出。
   - 右图展示 4B 各配置的样本内简化夏普与样本外简化夏普，标题为“4B（可调参数递增）”。
   - 右图横轴名称为“配置”，刻度依次为“配置 A”“配置 B”“配置 C”“配置 D”“配置 E”。各配置的可调参数数量见 4B 汇总表。横轴按配置等距排列，不把它当作等距的参数数量数轴。
   - 2 幅图的纵轴名称均为“简化夏普”，不标百分号；负数刻度使用数学负号“−”。
   - 蓝色线的图例为“样本内简化夏普”，红色线的图例为“样本外简化夏普”，2 条线之间的浅红色区域标为“样本内简化夏普与样本外简化夏普的差异”。该区域只突出 2 条曲线的差异，不表示差异率。
   - 图内层级编号和配置名称须与对应汇总表一一对应。最终检查文字不重叠、不裁切。
   - 保存到 `../book/images/08-rule-burden-4a-4b.png`

8. 打印分析：
   - 4A：比较各层增加交易规则或可调参数后，样本外表现是否改善。不得用这段样本外数据直接确定最终层级
   - 4B：观察可调参数增加后，样本内简化夏普与样本外简化夏普的差距怎样变化。不得据此确定最终配置
   - 引用交易规则负担的含义：交易规则本身也可能成为过拟合来源
   - 总结：如果 4 个可调参数已经够用，就没有必要只为改善样本内结果扩到 6 个

## 验收标准

固定样本内数据与样本外数据的切分后，使用相同冻结数据和运行环境时，Notebook 应复现以下关键结果。“样本内”和“样本外”后的数值均指简化夏普。

4A（交易规则堆叠）：
- 第 0 层基础固定参数：包含 1 种组合，样本内简化夏普为 0.86，样本外简化夏普为 0.20，简化夏普差为 −0.66，样本内累计收益率为 65.24%，样本外累计收益率为 3.62%
- 第 1 层优化再平衡间隔：包含 3 种组合，样本内简化夏普为 1.06，样本外简化夏普为 −0.14，简化夏普差为 −1.20，样本内累计收益率为 91.62%，样本外累计收益率为 −5.41%
- 第 2 层增加止损交易规则并优化止损阈值：包含 18 种组合，样本内简化夏普为 1.25，样本外简化夏普为 0.19，简化夏普差为 −1.06，样本内累计收益率为 111.99%，样本外累计收益率为 3.11%
- 第 3 层增加止盈交易规则并优化止盈阈值：包含 57 种组合，样本内简化夏普为 1.56，样本外简化夏普为 0.23，简化夏普差为 −1.32，样本内累计收益率为 113.48%，样本外累计收益率为 4.09%
- 第 4 层增加移动止损交易规则并优化移动止损阈值：包含 183 种组合，样本内简化夏普为 1.50，样本外简化夏普为 −0.36，简化夏普差为 −1.86，样本内累计收益率为 80.37%，样本外累计收益率为 −5.73%
- 第 5 层增加最大回撤风控规则并优化最大回撤风控阈值：包含 825 种组合，样本内简化夏普为 1.50，样本外简化夏普为 −0.46，简化夏普差为 −1.96，样本内累计收益率为 80.37%，样本外累计收益率为 −6.56%
- 第 3 层是当前样本外简化夏普数值最高层，但相对第 0 层的提升很小。第 4 层以后当前样本外表现明显变差。由于这段样本外数据已经用于比较各层，不能再把其中数值最高的一层当作经过独立验证的最终方案

4B（可调参数递增）：

- C：包含 3 个可调参数和 70 种组合，样本内简化夏普为 1.35，样本外简化夏普为 −0.62，简化夏普差为 −1.97
- D：包含 4 个可调参数和 420 种组合，样本内简化夏普为 1.37，样本外简化夏普为 −0.55，简化夏普差为 −1.92
- E：包含 6 个可调参数和 323 种组合，样本内简化夏普为 1.64，样本外简化夏普为 −0.69，简化夏普差为 −2.34
- 从 D 到 E，样本内简化夏普增加了 0.27，样本外简化夏普减少了 0.14，二者进一步背离
