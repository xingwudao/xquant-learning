# spec：亏了就跑——止损交易规则

> 在当前项目中执行命令，使用本 spec 指定的环境。遵守 TRAE 当前的权限设置；需要额外权限时，先说明原因和访问范围，取得用户确认后再继续，不要求关闭沙箱或启用“完全访问”。

## 上下文

在 `q4-when-to-trade.ipynb` 中已有：
- 简化风险平价权重分配方法在不同再平衡间隔下的回测结果
- 沿用 spec 01 的 `FEE_MODEL` 和 `run_backtest(frequency, fee_model=None, order_rules=None)` 辅助函数

定期再平衡只能在预定日期调整持仓，无法在 2 次再平衡之间主动应对下跌。

## 任务目标

给策略加上止损交易规则，比较不同止损阈值的效果。

## 执行要求

沿用 spec 01 的固定数据窗口：`START = "2021-01-01"`，`END = "2026-03-18"`。不得重新引入 `today` 或 `now`。

1. 阅读下列 open-xquant 源码，了解所列类、函数或方法的输入、输出和参数含义：
   - `oxq.rules.StopLossRule`（本实验将交易规则通过 `Engine.run(rules=[...])` 传入）

2. 解释 `StopLossRule` 的工作原理：
   - 当持有仓位时，`StopLossRule` 每个交易日以 `avg_cost × (1 - threshold)` 计算止损线，并用对应投资对象的当日收盘价判断该收盘价相对持仓平均成本的下跌幅度是否达到止损阈值
   - 达到止损阈值后，规则返回该投资对象的清仓目标。`Engine` 将目标转换成 `market` `SELL` 订单，`SimBroker` 按该投资对象的当日收盘价成交。说明市价单不指定成交价，锁定版本也不预先提交 `stop` 挂单
   - 明确同一收盘价用于判断和成交、且未模拟滑点，是本章的教学简化，不代表真实交易可以在看到收盘价后仍以同一价格成交
   - **为什么 `Signal` 做不到这件事**：`Signal` 只看市场数据（动量、波动率），无法读取持仓平均成本。止损判断需要知道“持仓平均成本是多少，当前价格相对它下跌了百分之几”——这需要由能够读取持仓状态的 `Rule` 处理

3. 从 spec 01 的回测结果中，**用代码动态选出**当前样本中计入交易成本后简化夏普最高的再平衡间隔作为后续基础配置（不要硬编码数字；也不能据此认定它在另一段未参与选择的数据上仍然最优）：
   ```python
   BEST_FREQ = max(FREQUENCIES, key=lambda f: results_with_fee[f].sharpe_ratio())
   ```

4. 定义 `STOP_THRESHOLDS = [None, 0.05, 0.10, 0.15]`，对应无止损配置，以及止损阈值分别为 5%、10% 和 15% 的配置，共 4 组。

5. 全部回测均计入交易成本（使用与 spec 01 相同的 `FEE_MODEL`）。调用 spec 01 定义的 `run_backtest` 辅助函数。无止损配置传入空列表，其余 3 种配置创建对应阈值的止损交易规则：
   ```python
   order_rules = [] if T is None else [StopLossRule(threshold=T)]
   run_backtest(
       frequency=BEST_FREQ,
       fee_model=FEE_MODEL,
       order_rules=order_rules,
   )
   ```
   在 `run_backtest` 内部，止损交易规则与 `RebalanceFrequencyRule` 一起传入 `Engine.run(rules=[...])`。以各阈值（含 `None`）为键，将返回的回测结果保存到 `results_sl` 字典中，并保留 `STOP_THRESHOLDS` 和 `BEST_FREQ`，供 spec 03 复用。

6. 打印对比表：止损阈值、累计收益率、年化波动率、最大回撤、简化夏普、成交笔数、总手续费。手续费显示保留 2 位小数，计算和差值比较使用未舍入值

7. 画净值曲线对比图（`figsize=(12, 6)`，画布大小为 12 英寸×6 英寸）：
   - 无止损配置的净值曲线使用灰色虚线。止损阈值为 5%、10% 和 15% 的配置分别使用红色实线、蓝色点划线和绿色点线。
   - 归一化到起点=100。横轴标“年份”，纵轴标“归一化净值（起点=100）”
   - 标题“止损阈值对比（计入交易成本）”

8. 在图中用浅红色阴影标出无止损配置的最大回撤时段，让学员直观看到这一段下跌的位置，便于和 3 条止损配置的净值曲线在同一时段对比走势。

9. 打印分析（根据实际数据描述结果方向，不要预设结果方向）：
   - 采用各止损阈值的配置相对无止损配置的最大回撤变化——是收窄了还是加深了？
   - 采用各止损阈值的配置相对无止损配置的年化波动率和简化夏普变化——分别是抬高还是压低？
   - 不同止损阈值（5%/10%/15%）之间的差异——哪个止损阈值在哪个指标上占优
   - 采用止损交易规则后，成交笔数和交易成本分别增加、减少了多少，还是没有变化？不要把成交增量直接等同于规则触发次数
   - “止损不是免费的——规则触发退出会产生卖出费用。后续再平衡如果买回，还会产生新的成交费用。”
   - “‘保护本金’听起来稳，但‘保护’在你这段数据上到底意味着收窄最大回撤、降低波动，还是别的什么——交给数据回答。”

10. 固定窗口参考结果（`START = "2021-01-01"`，`END = "2026-03-18"`，基础配置采用 spec 01 中当前样本计入交易成本后简化夏普最高的再平衡间隔，即每 10 个交易日再平衡），用于判断是否复现书稿：
    - 无止损配置：`101.68% / 11.19% / -12.81% / 1.31 / 372 / 3021.42`
    - 止损阈值为 5% 的配置：`100.79% / 10.71% / -13.25% / 1.36 / 389 / 3902.88`
    - 止损阈值为 10% 的配置：`100.32% / 11.01% / -13.08% / 1.32 / 378 / 3269.81`
