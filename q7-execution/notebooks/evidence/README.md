# 第7章保存结果与实现参考

本目录当前为内部编辑核验材料，不是已获准公开发布的数据包。作者返回的 M05–M09 结果材料只允许内部核验；最终公开版本应按授权范围另行整理，不得随本目录自动发布原始行情或结果 CSV。

## 只读重现与重新实验分开

- Notebook 第3步默认读取作者保存的逐日净值；第4步运行 `analyze_saved_fills.py`，从保存的成交记录重新计算比较结果。均不下载行情、不运行策略、不连接账户。
- `M05_simulation_fills.json`、逐日净值及两份比较 CSV 原样保留，来源为作者的 `M05-FINAL-20261103`。价格和费用保留原始精度，出版显示另按正文规则舍入。
- `spec03_implementation_reference.py` 是第3步的完整实现参考，依赖 Notebook 前两步的导入、函数和参数。它不是独立脚本；执行时可能下载行情、读取外部模拟账户，须由读者按正式 spec 主动使用。模拟盘提交开关默认关闭，提交前还须明确确认。不应为了查看保存图表而执行此文件。
- 当前展示结果来自同一 Yahoo Finance 数据下的 2 组本地模拟，不是 Alpaca 模拟盘成交。按实际成交日比较没有匹配组；日期映射后才能得到182个可比较组。映射日期是推定比较日期，不能保证对应同一订单。

## 原始币种标签的修正说明

原始成交 JSON 的 `order.currency` 保存为 `CNY`，原因是本地美股行情未显式提供币种属性，引擎使用了默认值。该实验使用 SPY、QQQ、GLD 的美元报价，初始资金和费用也按美元计算，并未做汇率换算。

编辑核验用同一完整行情快照分别设置 CNY、USD 后离线运行两组实验：净值、成交数量、成交价、费用完全相同，只有订单币种标签不同。因此保留原始 JSON，明确其标签缺陷，不重写作者封存结果。实现参考已在美股数据提供器中显式设置 `currency="USD"`，以后生成的订单使用正确标签。

## 资料覆盖边界

本目录可复算本书保存结果的净值比较和成交汇总。它不证明真实账户提交、成交或持仓核对已完成，也不保证重新下载的行情仍产生相同结果。原始行情快照仅在项目内部保存；公开资源是否包含这些结果文件须另行确认。
